## Критические травмы как карточки

В **0.1.0-alpha.5** добавлен компендиум **Critical Wounds** со всеми **24 травмами
основной книги**. Карточку можно перетащить на PC, NPC или монстра, выбрав место
ранения. Боевые критические попадания создают такие же карточки автоматически.

- Четыре состояния: **не обработано → стабилизировано → обработано → зажило**.
  На карточке указаны текущие штрафы и эффекты каждой стадии.
- Показаны медицинская DC, время обработки, DC магического лечения и нужное
  число успешных применений. First Aid стабилизирует; Healing Hands запускает
  заживление после нужного времени и одной успешной проверки.
- Есть проверки лечения, кнопки GM для результатов, полученных за столом,
  счётчик успешной магии и оставшиеся дни восстановления. Магический счётчик
  заполняется вручную и не реализует заклинания или расход их ресурсов.
- Зажившая обычная травма остаётся как история без штрафов. Постоянные
  последствия продолжают действовать, пока карточка остаётся на персонаже.
- Учитываются травмы используемой руки, зрительные проверки Awareness,
  множитель урона в голову при переломе черепа, ограничения STA, кровотечение,
  отравление и периодические проверки. Исправлена потеря проверки смерти при
  повреждении сердца, если после удара HP ещё выше нуля.

### Обновление

Установите [манифест alpha.5](https://github.com/alexch3706/WVTTfoundry/releases/download/v0.1.0-alpha.5/system.json)
через **Install from Manifest**, затем перезапустите мир. Старые карточки ран
сохраняют состояние; общий флаг кровотечения/отравления старого формата после
лечения нужно проверить по подсказке карточки: его источник раньше не записывался.

Для Foreign Object книга не даёт однозначной формулы перевода Critical Healing
в дни: срок задаёт GM. Смертельным травмам не назначается выдуманный срок
восстановления. Подробности — в [руководстве по карточкам](https://github.com/alexch3706/WVTTfoundry/blob/v0.1.0-alpha.5/docs/witcher/critical-wounds.md).

### Проверки

**240 автоматических тестов прошли.** Проверены переходы состояний, лечение, постоянные последствия, боевые эффекты,
права игроков, устаревшие запросы и откат при ошибках сохранения. Компендиумы
собраны и прочитаны обратно; **36 Actors и 1086 Items** проходят очистку
настоящими моделями Foundry V14. Архив проверяется при сборке.

Живая проверка на Forge остаётся за пользователем; [сценарии проверки](https://github.com/alexch3706/WVTTfoundry/blob/v0.1.0-alpha.5/docs/witcher/forge-checklist.md)
включают карточки, PC/NPC и несвязанные токены. Иллюстрации, ручные кубы и
отображение текущей брони из прошлых релизов сохранены.
